<h1 align="center">Bon Courage Tech</h1>
<p align="center"><strong>Rapidez. Qualidade. Entregas.</strong></p>

Construímos produtos digitais com engenharia de software, inteligência artificial e atenção à experiência de quem usa.

## Como trabalhamos

- **Clareza antes do código:** requisitos, fluxos, mockups e critérios de aceite.
- **IA com responsabilidade:** acelerar o trabalho com revisão humana e testes.
- **Código revisado:** mudanças por pull request e aprovação antes do merge.
- **Entregas verificáveis:** evidências, documentação e publicação controlada.

## Do requisito à entrega

Requisito → tarefa → branch → pull request → code review → validação → publicação.

Nossos repositórios de clientes são privados. O acesso é concedido individualmente, conforme o projeto e a responsabilidade de cada pessoa.
